# BMI Calculator -- Python Programming Internship

**Project:** Task 2 -- BMI Calculator

## 1. Project Overview

A Python-based BMI Calculator developed with Tkinter. The application
provides a graphical interface where the user enters height and weight,
calculates Body Mass Index (BMI), and displays the corresponding BMI
category.

## 2. Features

-   Tkinter graphical user interface.
-   Height and weight input fields.
-   BMI calculation using the standard BMI formula.
-   Validation for non-numeric input.
-   Validation to prevent zero or negative height and weight.
-   Display of calculated BMI.
-   BMI category classification:
    -   Underweight
    -   Normal
    -   Overweight
    -   Obese
    -   Clinically obese

## 3. Technologies Used

-   Python
-   Tkinter
-   VS Code
-   Git and GitHub

## 4. BMI Formula

The application calculates BMI using:

``` text
BMI = weight / height²
```

Weight is entered in kilograms and height in metres.

## 6. How to Run

1.  Install Python.
2.  Open `BMI Calculator.py` in VS Code.
3.  Run the program.
4.  Enter height in metres.
5.  Enter weight in kilograms.
6.  Click the calculation button to display the BMI and category.

## 7. Input Validation

The application checks that:

-   Height is a valid number.
-   Weight is a valid number.
-   Height is greater than zero.
-   Weight is greater than zero.
